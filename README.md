# my-demo-agent

A simple Python demonstration agent that provides utility functions such as generating prime numbers.

## Features

- `get_prime_numbers(n)`: Returns a list of all prime numbers up to `n`.
- Easy to integrate into other projects.

## Installation

Clone the repository and run the script with Python 3.6+.

```bash
git clone https://github.com/yourusername/my-demo-agent.git
cd my-demo-agent
python3 demo.py
```

## Usage

Import the function in your code:

```python
from demo import get_prime_numbers

primes = get_prime_numbers(50)
print(primes)
```

Running `demo.py` will demonstrate example usage and print prime numbers up to 20.
